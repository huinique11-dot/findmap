# 우리동네 배움지도

학교 주변의 지역 교육자원(관공서, 문화예술 기관, 체험시설, 도서관, 청소년·돌봄 시설, 마을교육 기관)을 지도에서 찾고, 지역연계 교육과정 수업계획을 만드는 웹앱입니다.

- **설치·로그인·초기 설정이 없습니다.** 주소를 열면 바로 쓸 수 있습니다.
- **PC와 스마트폰에서 모두 됩니다.** 스마트폰에서는 지도 아래에 끌어 올리는 목록이 나옵니다. 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수도 있습니다.
- 인천 남동구·연수구의 초·중학교 115곳과 지역 교육자원 142곳이 기본으로 들어 있고, 위치(위도·경도)도 미리 넣어 두었습니다.

## 사용법 (3단계)

1. **우리 학교 선택**: 위쪽 칸에 학교 이름을 입력합니다. 지도가 학교 주변으로 이동하고, 목록이 가까운 순서로 정렬됩니다.
2. **장소 찾기**: 분류 버튼(관공서·문화예술, 도서관 등), 지역, 거리(1·2·3·5km)로 걸러 봅니다. 장소를 누르면 주소, 전화, 길찾기(카카오맵)가 나옵니다.
3. **수업에 담기**: `☆ 담기`를 누르면 **수업계획** 탭에 모입니다. 교과·학년, 활동일, 활동 내용을 적은 뒤 **엑셀(CSV) 저장**이나 **인쇄**를 누릅니다.

학교를 고른 뒤의 주소(예: `...#school=인천만수초등학교`)를 동료에게 보내면, 받은 사람에게도 같은 학교가 선택된 상태로 열립니다.

## 자료 추가

**자료추가** 탭에서 두 가지 방법으로 장소를 더할 수 있습니다.

- **엑셀 업로드**: 기존 양식과 같은 열(`이름, 내용, 주소, 전화번호, 위도, 경도`)의 .xlsx/.csv 파일을 올립니다. 위도·경도가 비어 있으면 주소로 위치를 자동으로 찾습니다.
- **지도에서 직접 추가**: 버튼을 누르고 지도에서 위치를 누른 뒤 이름과 분류를 적습니다.

추가한 장소와 수업계획은 **그 기기의 브라우저에만** 저장됩니다. 모든 선생님이 함께 볼 기본 자료를 바꾸려면 아래 "기본 자료 바꾸기"를 따르세요.

## 배포 (GitHub Pages, 한 번만)

1. GitHub 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 이 앱이 있는 브랜치(`main` 등)와 `/ (root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 나옵니다. 이 주소를 선생님들께 공유하면 됩니다.

서버나 데이터베이스가 필요 없는 정적 파일이라 다른 웹 호스팅(학교 홈페이지 서버, Netlify 등)에 파일을 그대로 올려도 동작합니다.

## 기본 자료 바꾸기 (관리자용)

기본 자료는 `data/places.js` 한 파일입니다. 엑셀이 바뀌면 아래처럼 다시 만듭니다(파이썬 3, `openpyxl` 필요).

```bash
python3 tools/extract.py 학교목록.xlsx 기관목록.xlsx raw.json
```

```bash
python3 tools/geocode.py raw.json geo.json
```

```bash
python3 tools/build_data.py geo.json data/places.js
```

`geocode.py`는 OpenStreetMap(Nominatim)으로 주소를 좌표로 바꿉니다(1초에 1건). 주소로 못 찾으면 기관 이름, 그다음 도로명으로 찾고, 도로명으로만 찾은 곳은 앱에 "위치가 대략적일 수 있어요"로 표시됩니다. 엑셀에 위도·경도를 직접 적어 두면 그 값을 우선 쓰도록 `geo.json`을 고쳐도 됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구성 |
| `app.css` | 디자인 (PC·모바일 반응형, 인쇄용) |
| `app.js` | 지도, 검색·필터, 수업계획, 자료 추가 |
| `data/places.js` | 기본 자료 (이름·분류·주소·전화·좌표) |
| `tools/` | 엑셀 → 기본 자료 변환 스크립트 |
